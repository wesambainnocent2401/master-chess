# Master Chess

An online chess platform built with vanilla JavaScript and Firebase.

## Phase 1 (current)
Landing page, registration, login, password reset, and player dashboard.

## Setup
1. Create a Firebase project with a Web app.
2. Enable Email/Password sign-in and create a Firestore database.
3. Paste your Firebase config into `js/config.js`.
4. Publish the Firestore rules from the project docs.
5. Deploy the folder to Vercel through GitHub.

## Stack
HTML, CSS, JavaScript (ES modules), Firebase Auth, Firestore, Vercel.# master-chess
